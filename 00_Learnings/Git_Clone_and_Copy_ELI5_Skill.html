Understanding the ELI5 Skill Setup Commands

These commands download the ELI5 repository from GitHub, then copy its eli5 skill folder into Claude Code's user-level skills directory.

The commands

git clone https://github.com/DreambigOu/ELI5.git
cp -r ELI5/skills/eli5 ~/.claude/skills/eli5

What each command does

  1. git clone https://github.com/DreambigOu/ELI5.git downloads the repository into a new local folder named ELI5 in your current directory.
  2. cp -r means “copy recursively,” so it copies the source directory and its contents, including nested files and folders.
  3. ELI5/skills/eli5 is the source skill directory inside the cloned repository.
  4. ~/.claude/skills/eli5 is the destination. The ~ represents your home directory; .claude is Claude Code's user configuration folder.

Before running the copy command

Run the commands from the same directory where you want the ELI5 clone created. The destination's parent folder ~/.claude/skills must already exist, or the copy command will fail.

Windows PowerShell equivalent

The shown cp -r syntax is intended for macOS/Linux shells. In PowerShell, create the destination directory if needed, then copy the skill folder like this: 

git clone https://github.com/DreambigOu/ELI5.git
New-Item -ItemType Directory -Force "$HOME\.claude\skills" | Out-Null
Copy-Item -Recurse "ELI5\skills\eli5" "$HOME\.claude\skills\eli5"

After copying, the skill's files should be inside $HOME\.claude\skills\eli5. This lesson explains the commands; it does not run them.
