JavaScript Strings: charAt() vs at()

Both methods read a character at an index. JavaScript indexes strings starting at 0, so for "abc", index 0 is "a". 

const text = "abc";

text.charAt(0); // "a"
text.at(0);     // "a"

Difference table

Feature charAt() at()
Purpose Returns the character at an index. Returns the character at an index.
Index 0 in "abc" "a" "a"
Negative indexes Not supported; returns an empty string. Supported; -1 means the last character.
Example: index -1 "abc".charAt(-1) → "" "abc".at(-1) → "c"
Out-of-range index Returns an empty string. Returns undefined.

Watch the capitalization

The method name is charAt, with a capital A. JavaScript is case-sensitive, so "abc".charat(0) is not the correct method name and throws a TypeError. Use "abc".charAt(0).
